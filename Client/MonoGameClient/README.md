# MonoGameClient

This is a new standalone MonoGame project scaffold for the MMO framework repository.

## Run

```bash
dotnet run --project Client/MonoGameClient/MonoGameClient.csproj
```

## Controls

- Move: `WASD` or arrow keys
- Quit: `Esc`

The sample draws a movable square so you can verify that MonoGame is initialized and rendering.
